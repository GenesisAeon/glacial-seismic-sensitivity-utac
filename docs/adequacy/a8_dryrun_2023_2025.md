# A8 dry run on legacy data (2023–2025 pseudo window)

**FUNCTIONAL TEST ONLY. This is not a C2 result and says nothing about C2 or about the glacier
hypothesis.** Its purpose is to check that the real gate code path runs end to end, and to measure
runtime and memory before the A8 freeze. Run on 2026-10-22, script `scripts/a8_dryrun_2023_2025.py`,
raw output `results/adequacy/a8_dryrun/dryrun_2023_2025.json`.

## Set-up

| | Choice |
|---|---|
| Data | frozen snapshots `results/adequacy/b_value/comcat_ak_*_2016_2025.csv.gz` only; no download. The script aborts if any event lies at or after 2026-01-01 (none did). No 2026+ or 2027+ data touched. |
| Pipeline | `catalog.prepare` with the region definition → Mc cut ≥ 2.1 (as `catalog.b_value`) → binning 0.1 (inside `prepare`) |
| Model | frozen baselines (`load_baselines`, SHA-checked) and frozen b-values (`load_b_values`, SHA-checked) |
| Pseudo test window | 2023-01-01 ≤ t < 2026-01-01 (3 years) |
| History (triggers only) | 2022, as C2 uses the year before its window |
| T3 reference | 2016-01-01 ≤ t < 2023-01-01 (7 years; it must not overlap the pseudo window, so 2016–2025 as in A8 is not possible here) |
| Resolution | T1: 10,000 simulations; T2: B = 10,000; one fixed seed 20261022 (dry-run seed only, not the A8 seed) |
| Rule | `gate_lenient_t3` (L + T3); S and L reported for comparison |

## Runtime and memory (box, 1 process)

| Step | Time |
|---|---|
| T2 SE_Alaska_AK (3,183 window events, B = 10,000) | 423 s |
| T1 Interior_AK_ctrl (10,000 sims) | 6 s |
| T2 Interior_AK_ctrl (692 window events, B = 10,000) | 147 s |
| **Total** | **576 s (≈ 9.6 min)** |
| **Peak RSS** | **762 MB** |

Memory did not blow up. `simulate_window` keeps all simulated catalogues in memory, so memory
grows with n_sim × events per catalogue. The 2036-12-31 look (10-year window) will need roughly
3× the per-catalogue size of this run; streaming the bootstrap (compute D_b per catalogue, then
drop it) would keep it flat. **Update 2026-10-23:** the streaming path is now in the code (#7) and
the 2036 look was measured instead of estimated, see `a8_dryrun_2036_projection.md`.

Gate: **L + T3 not triggered**, L not triggered, S triggered (through the glacier tests).
Under A8 the glacier failures would be reported as qualifications only.

## Pipeline findings

1. The whole path ran without errors: SHA checks, `prepare`, Mc cut, T1, T2 bootstrap, T3, rule.
2. Reference counts over the full 2016–2025 reference recomputed from the snapshots: 5,442
   (SE_Alaska_AK) and 2,098 (Interior_AK_ctrl), matching `b_value_2016_2025.json`.
3. The glacier window 2023–2025 has 3,183 events above Mc, against 225 in 2022. T2 and T3 of the
   glacier region reject strongly. This is in-sample data (the frozen model was fitted on data up
   to 2025), so it is not interpretable as a test; it does show that glacier-region failures
   occur in real data and that the qualification rule matters.
4. The T2 p-value hits its floor 1/(B + 1) ≈ 0.0001 in the glacier region, as expected with
   B = 10,000.
5. Memory is acceptable at 3 years; see the streaming note above for the 10-year look.
